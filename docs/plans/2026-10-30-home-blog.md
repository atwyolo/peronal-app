# Plan: Home Blog block

Replace the last temporary dump with the three latest posts: a featured card plus two on desktop, a carousel on mobile. The home page ends here: the footer is dropped (owner's decision, 2026-10-30).

Related: [[2026-10-29-home-page-design]], [[Home Page Handoff]]. Previous: [[2026-10-30-home-skills]]. Next: [[2026-10-30-home-motion]].

## Decisions

- **Reuse the Carousel** from [[2026-10-30-home-experience]], with the same one-DOM rule.
- **Links:** post cards go to `/blog/<slug>`, "All posts" to `/blog`. Both are 404 until Stage 4, like the rest of the navigation.
- **Time zone:** `timeZone: "UTC"` in the i18n request config. Without it next-intl uses the machine's zone, so a local build and a Vercel build could print different dates for the same post.
- **Excerpt** renders as plain text through `toPlainText`, because the card is 2–3 sentences with no formatting.
