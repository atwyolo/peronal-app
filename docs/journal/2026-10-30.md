# 2026-10-30 — Home page: photo, Image adapter, contacts

## Decided
- The photo and CV go to a public Vercel Blob store by hand, through the dashboard (owner's decision); no upload script until the admin exists.
- Photo master: 4:5, 1600×2000, JPEG q90, sRGB, no EXIF. The visitor never downloads it: `next/image` encodes a copy per width, so the output settings decide the weight.
- Real WhatsApp and LinkedIn logos on the contact buttons (owner's decision), copied from `simple-icons` (CC0) instead of adding a dependency.
- `qualities: [85]` (owner's goal: smallest file without visible loss), measured on the real photo. `object-position: 50% 0` instead of the handoff's `50% 12%` (owner agreed).
- Remaining order confirmed: Experience, Skills, Blog, motion pass. The footer is dropped (owner's decision). "Learn more" on experience cards goes to `/projects`, a 404 for now (owner's decision).

## Gotchas
- `next start` reads `next.config.ts` at startup, so a quality list changed after the build still applies.
- The long CV URL in the temporary dump overflowed the mobile page by 4 px. `e2e/header.spec.ts` caught it: the visual viewport shifted by 9 px, so the header looked scrolled away while sticky worked correctly. Fixed with `break-all` on that line; the line goes away with the contacts step.
- A "not less than 56px" assertion let a wrapped 67 px mail button pass; the screenshot caught it, and the test now expects exactly 56 px in the design frames.
- After about 20 quick curl requests in a row, blob URLs started answering 403 with the Vercel Security Checkpoint (`x-vercel-mitigated: challenge`), and were still doing so several minutes later. The burst is the likely cause, not a confirmed one; whether it covers one IP or the whole store is unknown. Do not loop over blob URLs when measuring.
- The dev server kept serving the old `--color-whatsapp-foreground` after `globals.css` changed, and even a `touch` of the file triggered no rebuild, while the production build had the new value. A restart cleared it. When a style looks stale, compare the served CSS with the source before changing code.
