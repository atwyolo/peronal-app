# 2026-10-29 — Home page architecture, step 1

## Decided
- Adapted Feature-Sliced Design: `views` / `widgets` / `features` / `shared`, `src/app` for routes only, `src/db` outside the layers.
- No barrel files; public files rule enforced by lint.
- `shared/ui` adapters with their own API over shadcn; shadcn files move to `shared/shadcn`.
- CSS-only animation, content never hidden by JS; home stays static.
- Localization and theme ship with the home page, one functionality at a time.

Full detail: [[2026-10-29-home-page-design]].

- Delivery: small steps, one step per commit.
- Owner's code style rules (now in `CLAUDE.md`): PascalCase for JSX files, `FC` arrow components with props destructured on the first line, hooks typed on input and output, hook files camelCase (`usePosts.ts`).

- File naming stays a convention, not a lint rule (owner's decision).
- Server Actions in `src/actions/`, Zod schemas in `src/schemas/`, both outside the layers without import-order rules; action result shape `{ ok, errors }` (ADR-0006 updated).

## Done
- Step 1, structure move + boundaries lint: shadcn → `src/shared/shadcn/ui`, `src/lib` → `src/shared/lib`, home data dump → `src/views/home/HomePage.tsx`, thin `src/app/page.tsx`, root layout in the new component style, `components.json` aliases repointed.
- `eslint-plugin-boundaries` 7.4 configured with `policies`. Checked with throwaway files: 9 deliberate violations reported, allowed imports pass. Gotcha: the rule ignores packages unless `checkAllOrigins: true`.
- Verification: `test:run`, `test:e2e`, `lint`, `tsc --noEmit`, `build` all green; `/` still static.
