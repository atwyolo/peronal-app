# 2026-10-28 — Database layer for the home page

## Decided
- One Neon database for local dev, previews and production; schema synced with `drizzle-kit push`, no migration files. See [[ADR-0002 Database and ORM]].
- Home page data model agreed with the owner. See [[Data Model]].
- Locale fallback is per field (`coalesce(requested, en)`), not per row.
- Post tags are free-form `text[]` per locale; hero chips are skills with `main = true`; Express added to skills.

## Done
- Vercel project `personal-app` connected to GitHub; Neon added through the Vercel integration (no preview branching).
- Packages: `drizzle-orm`, `@neondatabase/serverless`, `drizzle-kit`, `tsx`, `@next/env`, `server-only`, `libphonenumber-js`.
- Schema in `src/db/schema/`, client in `src/db/index.ts`, config in `drizzle.config.ts`, scripts `db:push`, `db:seed`, `db:studio`.
- Seed script (`src/db/seed/`): fills empty tables only.
- Cached queries for the home page in `src/db/queries/home.ts`; temporary data dump on `/`.

## Notes
- `drizzle-kit export` ignores `casing` from the config and prints camelCase columns; `push` and `generate` honour it.
- Neon Auth environment variables were created by the integration; we do not use them (own auth in Stage 6).
