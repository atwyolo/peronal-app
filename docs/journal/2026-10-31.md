# 2026-10-31 — Home page: Experience block closed

## Decided
- `Image` gets a `framed` prop instead of a class from the parent: only `Image` knows a load failed, so only it can draw the placeholder's border.
- The card placeholder has the prototype's 1 px lines but no "COMPANY IMAGE" text (Claude's call). The photo's placeholder does not change.
- The Experience block is closed (owner's decision). The owner checked it in Safari on an iPhone against the dev server and found no artifacts.
- Card images are closed until the admin, where the owner completes and corrects the content (owner's decision).
- Three carousel items closed without code (owner's decision). The track never gets horizontal padding: rule in [[2026-10-29-home-page-design]] and on the `className` prop.
- New working rules from the owner, in `CLAUDE.md`: teach in every reply, learning content stays in the chat, every decision is reported with its alternatives. `docs/learning/` and the learning note template are removed, together with the journal lines that only explained how a tool works. No ADR: this is a working rule, not an architectural decision (Claude's call).
- The rotation bug is fixed with a `ResizeObserver` on the `Carousel` track (owner's decision). Alternatives and findings: [[2026-10-30-home-experience]].
- No WebKit project in Playwright for now (owner's decision): it did not show the rotation bug, and the four tests that failed there were test assumptions. iPhone behavior is checked in the iOS simulator instead; the question comes back before the motion pass.
- `allowedDevOrigins` lists the whole `192.168.1.*` subnet (owner's decision), so opening the dev server on a phone survives a new address from the router. It covers every device on the home network, and only the dev server.

Detail: [[2026-10-29-home-page-design]].

## Notes
- The first real image broke two e2e tests, as data-backed tests do: the placeholder test assumed Glovo had no image, and the photo test counted every `_next/image` response. The placeholder test now fails every image with a 404, the photo test matches its source file.
- The first version kept the photo's 8 px stripes on the card. The computed style passed, and the dashed border was there, but it did not read: stripes and border share the `placeholder` color. Review caught it, not the test.
- The first version of the rotation fix left the track blank on card 4 in the simulator while every automated test stayed green. Reason and guard are in the plan.
- The first `lg` test passed against a deliberately broken build: `expect.poll` read the offset Chromium brings back before the resize observer had run. It now waits for the frames first.
- The simulator's Safari can serve a page from its cache for an address it has seen, which silently tests an older build. Each check needs fresh addresses and `no-store`.
