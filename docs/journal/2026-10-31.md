# 2026-10-31 — Home page: Experience card image

## Decided

- The card placeholder has the prototype's 1 px lines but no "COMPANY IMAGE" text (Claude's call). The photo's placeholder does not change.

## Done
- Experience block, task 3: 140/180 px image area in `ExperienceCard`, `alt` is the company name. Checked on screenshots at 390 and 1280 in both themes.
- First card image: the owner uploaded `glovo.png` and wrote its URL to the database; the other three jobs keep the placeholder. The URL is in the seed data too.

## Notes
- The first `sizes` was the box width, `calc(25vw - 62px)`. That is the trap the photo hit: with `object-cover` a 16:9 file in a 258×180 box renders 320 px wide, so from 1024 to about 1272 a 1x screen got a 256 px file. Neither the placeholder nor the review could show it; the first real image did. Now `max(320px, 25vw - 62px)`.
- The first real image broke two e2e tests, as data-backed tests do: the placeholder test assumed Glovo had no image, and the photo test counted every `_next/image` response. The placeholder test now fails every image with a 404, the photo test matches its source file.
- The first version kept the photo's 8 px stripes on the card. The computed style passed, and the dashed border was there, but it did not read: stripes and border share the `placeholder` color. Review caught it, not the test.
